Brain Tumor Detection System

An end-to-end web-based Brain Tumor Detection System developed using Flask
and Deep Learning to classify MRI images and identify the presence and
type of brain tumors.

This project focuses on integrating machine learning models into a
complete software system, including validation, backend logic,
authentication, and data storage.



 Features
- MRI image validation before prediction
- Brain tumor detection and classification using CNN models
- User authentication (Login / Register)
- Session-based prediction history
- Multilingual support (English / Hindi)
- PDF report generation
- SQLite database integration
- Clean and modular project structure

  Tech Stack
- Backend: Python, Flask
- Deep Learning: TensorFlow, Keras
- Database: SQLite
- Frontend: HTML, CSS, Bootstrap
- Tools: Git, GitHub
